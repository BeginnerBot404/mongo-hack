# Offline reference docs (hackathon snapshot)

Snapshots of official vendor docs fetched on **2026-09-26** with `curl -sL`, for offline grep. They are **snapshots**: APIs drift, so re-fetch from the Source URL column if something looks off. Most sources serve markdown by appending `.md` to a page URL, and each vendor publishes an `llms.txt` index (copied as `_llms-index*.md` in its folder).

Notes:
- `mongodb/*.md`: pages contain every driver language flattened together (tabs are not labeled); grep for `javascript`/`js` fences or `node`. Long literal embedding arrays in examples were truncated to 3 floats + a `/* ...embedding floats truncated by snapshot... */` marker to keep size down; nothing else was edited.
- `openrouter/`: `llms-full.txt` was 4.8MB and multi-language, so specific pages were fetched instead. The `apiref-*` files are full OpenAPI-derived references (large).
- `voyage/mongodb-voyageai_*`: Voyage models as served through MongoDB Atlas (docs on mongodb.com); `voyage/docs_*` and `reference_*` are docs.voyageai.com.
- `langgraph-js/`: LangGraph.js + LangChain.js pages from docs.langchain.com/oss/javascript (the JS `llms.txt` index is truncated at ~40KB and omits langgraph pages; paths were taken from the Python index and swapped to /javascript/).
